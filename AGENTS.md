# Agent Instructions

This repository contains reusable Agent Skills for Chinese WeChat Official Account content creation.

## Skill Routing

### wechat-vertical-mini-account

When the user asks for any of the following, read and apply `wechat-vertical-mini-account/SKILL.md`:

- 微信公众号 or 公众号 content
- 垂直小号
- 起号方案
- 选题 / 标题 / 爆款文章
- 微信搜一搜 SEO
- 流量主 / 商单 / 私域 / 知识付费
- content review for compliance and lower-risk publishing
- 账号定位 / 人设 / 简介 / 自动回复
- 数据复盘 / 内容复盘

### multi-product-buying-guide-writing

When the user asks for any of the following, read and apply `multi-product-buying-guide-writing/SKILL.md`:

- smartphone buying guides or 手机推荐 / 手机选购
- price-drop lists or 降价盘点
- multi-product comparison or 横评
- ranking articles or 排行榜
- budget recommendations like 2000元档 / 3000元档
- consumer decision articles for tech products

### single-product-price-drop-writing

When the user asks for any of the following, read and apply `single-product-price-drop-writing/SKILL.md`:

- single phone price-drop analysis or 降价捡漏
- clearance deals or 清仓
- 618 / 双十一 / 国补 timing articles
- old flagship bargain analysis or 旧旗舰
- "is this phone worth buying now" decision content
- storage price hike or memory price articles

### When multiple Skills match

- For multi-product recommendation lists, prefer `multi-product-buying-guide-writing`.
- For single-product price-drop / clearance analysis, prefer `single-product-price-drop-writing`.
- For general account strategy, topic selection, or non-tech content, use `wechat-vertical-mini-account`.
- Skills can be combined: use `wechat-vertical-mini-account` for account strategy and a buying-guide skill for article content.

## General Rules

Keep outputs practical, Chinese-first, and ready to copy into a publishing workflow.

Do not help with:

- fake traffic, fake followers, fake screenshots, or fake cases
- inducing users to click ads
- plagiarism, wash-writing, or content theft
- evading platform detection in deceptive ways
- exaggerated medical, financial, educational, or income claims

For named creator styles, extract reusable article structure and decision logic only. Do not impersonate the creator, copy private catchphrases, or fabricate biographical claims.

When data is missing, use clearly marked assumptions or ask for the minimum needed details. Do not fabricate facts, prices, metrics, screenshots, or policy rules.
