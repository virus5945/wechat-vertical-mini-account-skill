# 示例输出

## 示例 1：资料较完整的单品降价分析

用户输入：

```text
使用 single-product-price-drop-writing。
机型 A，12GB+512GB，发布价 3799 元，当前平台参考价约 1999 元。主打大电池、护眼屏和卫星消息，目标读者是给爸妈换机的人。
```

推荐输出：

```markdown
# 从 3799 到约 1999，机型 A 现在适合给爸妈换吗？

给爸妈换手机，很多人第一反应是买便宜的。但真正用下来，便宜不是唯一标准，续航、屏幕、信号和耐摔才更影响体验。

机型 A 现在值得单独聊，关键不只是价格降了，而是它的卖点刚好贴合爸妈的使用场景。

当初 12GB+512GB 版本发布价是 3799 元，现在公开页面参考价约 1999 元。这里要注意，活动价、补贴和库存会随平台变化，实际下单前一定要再看店铺页面。

它最大的优势是大电池。对爸妈来说，少充电、出门不用一直担心电量，比跑分高多少更有感知。

第二个优势是护眼屏。长时间刷视频、看新闻、回消息，屏幕舒服比参数好看更重要。

卫星消息属于加分项，不是每个人都需要，但如果家里老人经常外出、旅游或者去信号不稳定的地方，这类功能会更有安全感。

短板也要说清楚：如果你追求极致拍照、轻薄手感或者最新旗舰性能，它不一定合适。它更像是一台给长辈日常用、省心用的机型。

我的判断是：如果当前参考价还在 2000 元左右，且你主要需求是给爸妈换一台续航稳、存储够、功能全面的手机，可以考虑。要是价格恢复到更高区间，吸引力就会下降。
```

## 示例 2：资料不足时的安全输出

用户输入：

```text
使用 single-product-price-drop-writing。
帮我写一篇某款手机降价捡漏文，我只知道它最近便宜了。
```

推荐输出：

```markdown
我先给你搭一个安全版结构。因为缺少机型、价格、配置和来源，我不会写具体金额、库存、销量或排名。

## 标题方向

1. 这款手机现在能不能入手？先看价格、配置和短板
2. 手机降价后别急着冲，真正要看的是这 4 个点
3. 旧机型降价后值不值得买？普通用户先看这份判断清单

## 正文结构

1. 市场背景：为什么现在会降价，可能是新机上市、活动促销或库存调整。
2. 价格锚点：补充发布价、当前参考价、版本和平台来源。
3. 核心卖点：只选一个最强理由，不要参数全堆。
4. 使用场景：把参数翻译成日常体验。
5. 明确短板：老机型、重量、影像、性能、系统周期等。
6. 购买结论：适合谁，不适合谁，什么价格区间更值得看。

## 需要补充的信息

- 手机型号和版本
- 发布价、当前参考价、价格来源
- 3 个核心配置
- 目标读者是谁
- 你希望偏稳妥还是偏强观点
```
