# 公众号文章工作流

## 1. 六步写作法

### 第一步：选题

明确这篇文章解决什么问题，不要一上来就写正文。

输出：

- 目标读者是谁。
- 读者现在有什么痛点。
- 看完能得到什么。
- 这篇文章和账号标签有什么关系。

### 第二步：大纲

优先用 3-5 个小节，不要堆太多观点。

通用大纲：

```markdown
开头：场景/冲突/反常识
核心观点：一句话说清
小节 1：为什么会这样
小节 2：普通人最容易踩的坑
小节 3：更靠谱的做法
小节 4：具体行动清单
结尾：总结 + 互动/资料钩子
```

### 第三步：初稿

AI 可以写初稿，但必须给明确结构、读者和素材。

要求：

- 每段 2-4 句。
- 少用套话。
- 每个观点配场景或例子。
- 不编造事实、金额、人物、截图。

### 第四步：加个人经历

把“正确废话”改成真实判断。

可加入：

- 我之前也这么想，后来发现……
- 我见过很多人踩在这个坑上……
- 我不建议普通人一上来就……
- 这个东西真正有用的地方不是……而是……

### 第五步：润色节奏

重点优化：

- 开头 100 字是否抓人。
- 小标题是否能单独看懂。
- 段落是否太长。
- 是否有情绪起伏。
- 结尾是否有行动。

### 第六步：标题和 SEO

标题最后再确定。首段和小标题中自然放关键词。

## 2. 开头模板

### 认知颠覆式

大多数人以为【常识】，但我最近发现，真正的问题其实是【反转】。

### 场景代入式

你有没有遇到过这种情况：【具体场景】。表面上看是【表层问题】，实际背后是【深层问题】。

### 数据冲击式

如果用户提供了可信数据，可以用数据开头。没有数据时不要编造。

### 三连问式

你有没有想过：

【问题 1】？
【问题 2】？
最关键的是，【问题 3】？

### 共鸣唤醒式

很多人不是不努力，而是一直在用错误的方法努力。

## 3. 正文模板

### 模板 A：观点分析型

```markdown
# 标题

开头：提出一个反常识判断。

我的观点：一句话亮明态度。

## 一、表面问题是什么

## 二、真正的问题在哪里

## 三、普通人最容易踩的坑

## 四、我建议你这样做

结尾：回到开头，给行动建议。
```

### 模板 B：干货清单型

```markdown
# 标题

开头：目标人群 + 痛点。

## 第一个动作
场景 + 操作 + 注意事项

## 第二个动作
场景 + 操作 + 注意事项

## 第三个动作
场景 + 操作 + 注意事项

结尾：保存/转发/评论关键词。
```

### 模板 C：案例拆解型

```markdown
# 标题

开头：案例最有冲突的一幕。

## 他做对了什么

## 他避开了什么坑

## 这件事对普通人的启发

## 你可以复制哪一部分

结尾：强调不可盲目照抄。
```

### 模板 D：避坑指南型

```markdown
# 标题

开头：直接说一个常见误区。

## 坑 1：
为什么是坑 + 真实后果 + 怎么避开

## 坑 2：
为什么是坑 + 真实后果 + 怎么避开

## 坑 3：
为什么是坑 + 真实后果 + 怎么避开

结尾：给自查清单。
```

## 4. 结尾模板

### 三层递进式

```markdown
一句话总结：

现在你可以先做 3 件事：
1.
2.
3.

如果你也在做【领域】，可以在评论区说说你最卡在哪一步。
```

### 私域钩子式

```markdown
我整理了一份【资料名称】，里面包括【3 个具体内容】。

需要的话，关注后回复【关键词】领取。
```

注意：资料钩子必须真实存在，不能用虚假资料诱导关注。

## 5. 微信 SEO 清单

- 标题包含主关键词或长尾关键词。
- 第一段自然出现主关键词。
- 小标题覆盖关键词变体。
- 正文包含用户会搜索的问题句。
- 不堆关键词。
- 不牺牲阅读体验。

## 6. 去 AI 味清单

优先增加真实信息，而不是故意写错。

- 是否加入真实经历或真实观察。
- 是否有不完美但可信的判断。
- 是否删掉过度概括的万能句。
- 是否有具体动作，而不是抽象建议。
- 是否保留个人态度。
- 是否避免过于工整的排比。

## 7. 公众号排版建议

- 小标题短，能单独成立。
- 段落短，手机阅读不压迫。
- 重点句可以加粗，但全文不要超过 5-8 处。
- 一篇文章只解决一个核心问题。
- 不要在每段都用感叹号。
