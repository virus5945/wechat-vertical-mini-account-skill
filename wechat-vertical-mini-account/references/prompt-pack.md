# 提示词模板包

这些模板用于 Agent 内部执行或用户复制。使用时替换方括号内容。

## 1. 账号人设生成

```text
请根据下面信息，生成一个公众号垂直小号人设。

身份标签：[例如：创业者/开发者/数码内容作者/职场妈妈]
真实经历：[只写真实经历，不要编造]
研究领域：[例如：普通人 AI 工具/数码消费避坑/公众号起号]
目标人群：[例如：打工人/小老板/爸妈/内容创作者]
表达风格：[例如：大白话、犀利、温和、实战]

输出：
1. 一句话定位
2. 账号名称 10 个
3. 简介 10 个，15-35 字
4. 关注自动回复 3 版
5. 固定开头人设 3 版
6. 固定结尾人设 3 版
7. 内容边界：写什么/不写什么
```

## 2. 赛道评分

```text
你是一名内容策略顾问。请评估下面这些公众号垂直小号赛道。

赛道列表：
[粘贴赛道]

评分维度 1-10 分：
- 我的真实经验匹配度
- 用户刚需程度
- 搜索/讨论热度
- 竞争强度，分高代表竞争少
- 变现潜力
- 可持续更新能力
- 合规风险，分高代表风险低

输出表格，并给出最推荐的 3 个方向、最不建议的 3 个方向，以及每个方向的第一批 10 个选题。
```

## 3. 对标拆解

```text
请拆解下面这些公众号文章/账号，提炼可复用方法，不要照抄。

对标资料：
[粘贴标题/文章/账号信息]

请分析：
1. 标题用了什么吸引力技巧
2. 开头 3 句话如何抓住读者
3. 正文结构是什么
4. 情绪点在哪里
5. 哪些表达值得学习
6. 哪些地方不建议模仿
7. 可以迁移到我账号的 5 个选题公式
```

## 4. 选题筛选

```text
你是一位公众号选题编辑，请评估下面的选题。

账号定位：[填写]
目标用户：[填写]
选题列表：[填写]

请按以下维度评分：
- 痛点强度
- 情绪共鸣
- 实用性
- 时效性
- 变现潜力
- 账号匹配度
- 标题空间
- 合规风险

输出表格，选出最值得写的 3 个，并说明推荐理由。
```

## 5. 标题生成

```text
请为下面选题生成公众号标题包。

选题：[填写]
目标用户：[填写]
文章核心观点：[填写]
风险偏好：[温和/犀利/爆款/低风险]

要求：
1. 温和版 5 个
2. 犀利版 5 个
3. 爆款版 5 个
4. 低风险版 5 个
5. 每个标题说明使用的公式
6. 标注不建议使用的高风险标题
```

## 6. 大纲生成

```text
请为下面公众号文章生成大纲。

标题：[填写]
账号定位：[填写]
目标用户：[填写]
核心观点：[填写]
素材/事实：[填写，不能编造]

要求：
- 开头 100 字要抓人
- 正文 3-5 个小节
- 每节包含观点、场景、建议
- 结尾有行动建议和互动问题
- 适合手机阅读
```

## 7. 初稿生成

```text
基于上面大纲，写一篇公众号文章。

要求：
1. 1200-1800 字
2. 口语化、真人化，有明确观点
3. 每段 2-4 句，适合手机阅读
4. 不编造数据、案例、收益、截图
5. 如果需要数据但没有来源，用“这里需要替换成真实数据”标注
6. 避免“首先、其次、最后”的机械结构
7. 结尾给出一个可执行动作
```

## 8. 真人化改稿

```text
请把下面文章改得更像真人写的公众号文章。

原文：
[粘贴]

改稿方向：
- 保留核心观点
- 加强个人判断和场景感
- 删除空泛套话
- 减少 AI 腔和过度工整排比
- 不故意写错字，不乱用标点
- 不新增未经确认的数据或案例

输出：
1. 修改后的正文
2. 主要修改点
3. 仍需用户补充的真实素材
```

## 9. 开头优化

```text
请为这篇文章写 5 个不同风格的开头，每个 80-120 字。

主题：[填写]
目标用户：[填写]
核心观点：[填写]

开头类型：
1. 认知颠覆式
2. 场景代入式
3. 三连问式
4. 共鸣唤醒式
5. 故事切入式

每个开头说明适合什么场景。
```

## 10. 结尾优化

```text
请为下面文章设计 3 个结尾。

文章主题：[填写]
目标：[引导评论/收藏/关注/回复关键词/私域转化]
资料钩子：[如果有，填写真实资料名称；没有就不要编造]

要求：
- 结尾 100-180 字
- 有总结，有行动
- 不强行营销
- 不诱导点击广告
```

## 11. 数据复盘

```text
请根据下面公众号后台数据做复盘。

账号定位：[填写]
数据表：[粘贴阅读、点赞、分享、评论、涨粉、私域]

请输出：
1. 本周最有效的选题公式
2. 最有效的标题公式
3. 阅读高但转化低的原因
4. 下周应该继续写什么
5. 应该停止什么
6. 下周 7 天排期
```

## 12. 合规审稿

```text
请对下面公众号文章做低风险审稿。

文章：[粘贴]

检查：
- 是否有虚假承诺
- 是否有诱导广告点击
- 是否有医疗/金融/教育等敏感绝对化表达
- 是否有未经证实的数据或案例
- 是否可能侵犯原创或洗稿
- 标题和正文是否匹配
- 私域引导是否过度

输出：
1. 风险点
2. 修改建议
3. 低风险改写版
```
